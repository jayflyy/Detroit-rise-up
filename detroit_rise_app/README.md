# Detroit Rise Community App 🏙️

A premium web application connecting Black-owned businesses in Detroit.

## Features
- **Business Directory**: Browse and search local businesses.
- **Messaging**: Send messages to businesses (simulated with local storage).
- **Community Events**: Discover upcoming events.
- **B2B Hub**: Barter and trade services.

## How to Run Locally
1.  Simply open `index.html` in any modern web browser.
2.  No server or backend is required!

## How to Deploy
This is a static web application (HTML/CSS/JS). You can deploy it to any static hosting provider for free:

### Option 1: Netlify (Recommended)
1.  Go to [netlify.com](https://www.netlify.com) and sign up.
2.  Drag and drop this entire folder onto the "Sites" dashboard.
3.  Your site will be live in seconds!

### Option 2: GitHub Pages
1.  Create a new repository on GitHub.
2.  Push these files to the repository.
3.  Go to Settings > Pages and enable GitHub Pages for the `main` branch.

### Option 3: Vercel
1.  Install Vercel CLI: `npm i -g vercel`
2.  Run `vercel` in this directory.

## Technologies
- Vanilla HTML5, CSS3, JavaScript (ES6+)
- Font Awesome (via CDN)
- Google Fonts (Outfit, Playfair Display)
